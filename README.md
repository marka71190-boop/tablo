# Табло «Пирамида» для трансляций

Сайт для ведения статистики русского бильярда и вывода табло в OBS.

- **Вход по паролю.** Пульт и управление доступны только оператору.
- **Несколько столов.** У каждого стола свой пульт и своя ссылка для OBS.
- **База игроков с фото.** Игрока выбирают на пульте из списка.
- **История матчей.** Статистика каждого матча, поиск, выгрузка в Excel (CSV) и резервная копия.
- **Свой сервер синхронизации.** Сторонние сервисы не нужны.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | Панель: столы, игроки, история, настройки (нужен вход) |
| `/t/<стол>` | Пульт стола (нужен вход) |
| `/o/<стол>` | Табло для OBS (открыто без пароля, только просмотр) |

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `ADMIN_PASSWORD` | да | Пароль оператора. Без неё пароль будет `admin`. |
| `DATABASE_URL` | очень желательно | Строка подключения PostgreSQL, например `postgres://user:pass@host:5432/db`. Без базы данные хранятся в файле и **стираются при каждом новом деплое** в Timeweb Apps. |
| `SESSION_SECRET` | нет | Любая длинная строка. Если её сменить, все операторы выйдут из системы. |
| `PORT` | нет | По умолчанию `8080`. |

## Публикация в Timeweb Cloud Apps

1. **Загрузите проект на GitHub.**
   - Создайте пустой репозиторий на github.com.
   - Нажмите «uploading an existing file» и перетащите все файлы из архива, сохранив папку `public`.
   - Нажмите «Commit changes».
2. **(Рекомендуется) Создайте базу данных.**
   - В панели Timeweb Cloud откройте «Базы данных» и создайте PostgreSQL.
   - Скопируйте строку подключения.
3. **Создайте приложение.**
   - Откройте Apps, нажмите «Создать» и выберите **Backend**.
   - Подключите GitHub и выберите репозиторий.
   - В поле «Фреймворк» выберите **Dockerfile**: он уже лежит в проекте, порт 8080.
4. **Задайте переменные.** В разделе переменных окружения добавьте `ADMIN_PASSWORD` и `DATABASE_URL`.
5. **Запустите деплой.** Когда он закончится, откройте технический домен приложения и войдите по паролю.

Если вместо Dockerfile выбрать фреймворк Express/Node.js, тоже будет работать: команда запуска `node server.js`, файл `server.js` лежит в корне.

## Как пользоваться

1. Откройте `/`, затем вкладку «Игроки», и добавьте игроков с фото.
2. Во вкладке «Столы» нажмите «Ссылка для OBS». Вставьте ссылку в OBS как источник «Браузер», ширина 1920, высота 1080.
3. Нажмите «Открыть пульт», выберите игроков из базы и ведите матч.
4. В конце матча нажмите «Сохранить матч». Результат и статистика попадут в историю, а на пульте начнётся новый матч с теми же игроками.

## Резервная копия

«Настройки» → «Скачать копию» сохраняет всё одним файлом: столы, игроков с фото и историю. «Восстановить из файла» возвращает данные обратно. Если база не подключена, скачивайте копию перед каждым обновлением сайта.

## Локальный запуск

```
npm install
ADMIN_PASSWORD=123 node server.js
```

Затем откройте http://localhost:8080
