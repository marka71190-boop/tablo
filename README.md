# Табло «Пирамида» для трансляций

Сайт для ведения статистики русского бильярда и вывода табло в OBS.

- **Вход по паролю.** Пульт и управление доступны только оператору.
- **Несколько столов.** У каждого стола свой пульт и своя ссылка для OBS.
- **База игроков с фото.** Игрока выбирают на пульте из списка.
- **История матчей.** Статистика каждого матча, поиск, выгрузка в Excel (CSV) и резервная копия.
- **Свой сервер синхронизации.** Сторонние сервисы не нужны.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | Панель: столы, игроки, история, настройки (нужен вход) |
| `/t/<стол>` | Пульт стола (нужен вход) |
| `/o/<стол>` | Табло для OBS (открыто без пароля, только просмотр) |

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `ADMIN_PASSWORD` | да | Пароль оператора. Без неё пароль будет `admin`. |
| `DATABASE_URL` | очень желательно | Строка подключения PostgreSQL, например `postgresql://gen_user:ПАРОЛЬ@хост:5432/default_db?sslmode=verify-full`. Без базы данные хранятся в файле и **стираются при каждом новом деплое**. |
| `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `DB_SSLMODE` | нет | То же, что `DATABASE_URL`, но по частям. Удобно, если в пароле есть символы `@ # / ? %` — их не нужно кодировать. |
| `DATABASE_CA` | нет | Содержимое файла `root.crt` из панели Timeweb. Если задано, сертификат базы проверяется; если нет — соединение всё равно шифруется. |
| `SESSION_SECRET` | нет | Любая длинная строка. Если её сменить, все операторы выйдут из системы. |
| `PORT` | нет | По умолчанию `8080`. |

## Публикация в Timeweb Cloud Apps

1. **Создайте приложение.** Apps → «Создать» → **Backend** → подключите GitHub, репозиторий `tablo`, ветка `main`. Фреймворк — **Dockerfile** (порт 8080).
2. **Подключите базу данных** (Базы данных → ваша PostgreSQL → «Способ подключения»). В приложении → «Переменные окружения» добавьте:

   ```
   ADMIN_PASSWORD = ваш пароль для входа
   DB_HOST        = хост из панели базы, вида xxxxxxxx.twc1.net
   DB_PORT        = 5432
   DB_USER        = gen_user
   DB_PASSWORD    = пароль пользователя базы (кнопка копирования в панели)
   DB_NAME        = default_db
   DB_SSLMODE     = require
   ```

   Либо одной строкой `DATABASE_URL` (если в пароле есть спецсимволы, их нужно закодировать: `@`→`%40`, `#`→`%23`, `/`→`%2F`).
   Если приложение и база в одной приватной сети, вместо домена можно указать приватный IP базы.
3. **Запустите деплой.** В логах должно быть: `Табло запущено на порту 8080, хранилище: postgres`. Если написано `file` — переменные базы не заданы.
4. **Подключите свой домен.** В приложении → «Настройки» → «Домены» → «Добавить домен», впишите домен (например `tablo.example.ru`).
   - Если домен в Timeweb («Домены и SSL»), DNS-запись создаётся автоматически.
   - Если домен у другого регистратора, создайте у него запись, которую покажет панель (A-запись на IP приложения или CNAME на технический домен).
   - Через 15–60 минут DNS обновится, SSL-сертификат Let's Encrypt выпустится автоматически.

Если вместо Dockerfile выбрать фреймворк Express/Node.js, тоже будет работать: команда запуска `node server.js`, файл `server.js` лежит в корне.

## Как пользоваться

1. Откройте `/`, затем вкладку «Игроки», и добавьте игроков с фото.
2. Во вкладке «Столы» нажмите «Ссылка для OBS». Вставьте ссылку в OBS как источник «Браузер», ширина 3840, высота 2160 (4K). Табло рисуется в полном разрешении, без растягивания. Если сцена в OBS 1920×1080, всё равно ставьте 3840×2160 и уменьшите источник по размеру сцены: картинка будет ещё чётче.
3. Нажмите «Открыть пульт», выберите игроков из базы и ведите матч.
4. В конце матча нажмите «Сохранить матч». Результат и статистика попадут в историю, а на пульте начнётся новый матч с теми же игроками.

## Экраны и возможности

- **Экраны:** счёт, VS, статистика партии и встречи, турнирная сетка, перерыв, победитель, спонсоры.
- **Бегущая строка** внизу, **история партий** над плашкой, **титр** комментатора или судьи на несколько секунд.
- **Перерыв:** обратный отсчёт, счёт, спонсоры, свой фон — картинка или видео MP4/WebM до 40 МБ.
- **Победитель:** фото в полный рост, золотые искры, статистика за турнир (по сохранённым матчам с тем же названием турнира).
- **Журнал ударов:** любое действие можно исправить или удалить, весь матч пересчитывается.
- **Компактный режим** пульта для телефона: шесть больших кнопок для игрока, у которого ход.
- **Мини-счёт для бокового ракурса:** ссылка `/o/<стол>?v=side` — всегда маленький счёт в углу (угол выбирается на пульте или параметром `&pos=tl|tr|bl|br`). Добавьте её отдельным источником «Браузер» в сцену боковой камеры. На основном табло мини-счёт включается кнопкой «Мини».
- **До скольки играют:** «до 5 побед» / «до 60 очков» выводится на плашке, мини-счёте и экранах статистики.
- **Парная игра (2 на 2):** галочка «Парная игра» вверху пульта. Игроки пары бьют строго по очереди (пара получила ход — к столу выходит следующий партнёр), пульт переключает сам; есть кнопка «Сменить игрока пары» для исправлений. На табло «Фамилия / Фамилия», бьющий подсвечен. Статистика — по паре.
- **Длинная свободная пирамида:** счёт очками до N (по умолчанию 60), любой забитый шар — очко, штраф — +1 очко сопернику. Для обычной пирамиды можно включить «Штраф: +1 шар сопернику».
- **Сетки bill4you:** выгрузка Excel с блоками «#N Стол X», верхней и нижней сеткой, «X» (проход), «ТП» и переходами «победитель/проигравший на #N» распознаётся автоматически. Большие сетки показываются на табло частями.
- **Турнирная сетка из Excel** (вкладка «Сетка»): колонки «Раунд, Игрок 1, Игрок 2, Счёт 1, Счёт 2, Стол, Время». Достаточно первого раунда. После «Сохранить матч» счёт попадает в сетку, победитель проходит дальше. CSV читается в UTF-8 и Windows-1251.

## Резервная копия

«Настройки» → «Скачать копию» сохраняет всё одним файлом: столы, игроков с фото и историю. «Восстановить из файла» возвращает данные обратно. Если база не подключена, скачивайте копию перед каждым обновлением сайта.

```
npm install
ADMIN_PASSWORD=123 node server.js
```
